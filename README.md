# dalyag.me

Static personal site: plain HTML/CSS/JS, no build step.

- `index.html` – homepage
- `pantheon.html` – all 37 פינת הפנתאון posts
- `accessibility.html` – accessibility statement
- `styles.css`, `main.js`
- `assets/` – images (WebP), icons, favicon, social preview image

Preview locally:

    python3 -m http.server 8000   # then open http://localhost:8000
